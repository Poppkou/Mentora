# Mentora

Простые уроки об искусственном интеллекте и ИИ-агентах для учителей. Одностраничный сайт: весь код в `index.html`.

- Часть 1 «ИИ с нуля» — 6 уроков для тех, кто никогда не пользовался ИИ.
- Часть 2 «ИИ-агенты» — 10 уроков о помощниках, которые выполняют задачу целиком.
- Страницы «Как пользоваться сайтом» и «Словарик».

Открыть локально: скачать `index.html` и открыть в браузере.

Прогресс сохраняется в браузере (localStorage). Задания с живым ИИ и облачное сохранение работают только при запуске сайта внутри Claude; в остальных случаях показывается готовый пример.
