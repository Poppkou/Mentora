# Mentora

Практикум по работе с ИИ для тех, кто уже пользуется ассистентами. Одностраничный сайт: весь код в `index.html`.

## Программа

| Модуль | Уроки | Доступ |
|---|---|---|
| 0. Введение | Как устроена Mentora; карта курса | бесплатно |
| 1. Инжиниринг промптов | Анатомия промпта; роль, контекст и примеры; Chain of Thought | бесплатно |
| 2. Декомпозиция задач | От цели к подзадачам; цепочки промптов и делегирование | полный доступ |
| 3. Продвинутые техники | Артефакты; генерация кода; анализ больших данных; свои GPT и агенты | полный доступ |
| 4. Ошибки и ограничения | Галлюцинации; проверка логики; конфиденциальность | полный доступ |

Уроки открываются по порядку. Уровень пользователя — число полностью пройденных модулей (0–5).

## Хранение состояния

- Прогресс: `localStorage['mentora:v2']` с полем версии схемы. Ключи прежних версий (`aic-*`) удаляются при запуске.
- Прогресс всегда непрерывный: неизвестные id и пропуски отбрасываются, повреждённые данные сбрасываются к уровню 0.
- Доступ: `mentora:v2:access`; журнал промокодов и неверных попыток: `mentora:v2:promo`.

## Для тестировщиков

- Режим тестировщика: открыть сайт с `?qa=1` (выключить — `?qa=0`). На странице «Доступ» появится панель: тестовая подписка, отключение подписки, отметка всех уроков, сброс прогресса, просмотр состояния.
- Промокоды проверяются в браузере и хранятся в коде только как SHA-256-хеши. Сами тестовые коды передаются отдельно.
- Это инструмент для тестирования, а не защита: доступ хранится в браузере и обходится вручную. Для настоящей оплаты нужна проверка на сервере.

Открыть локально: скачать `index.html` и открыть в браузере.


## Оплата и промокоды

Полный доступ: **1 550 ₽**, разовая оплата через ЮKassa (карта, СБП, ЮMoney). Уроки 1–5 бесплатны.

- Промокод на **скидку 5 %** → 1 472,50 ₽. Сумму со скидкой считает сервер, не браузер.
- Промокод на **доступ на 1 час** ко всем урокам, один раз на устройство.
- Сами коды в репозитории не хранятся (только SHA-256), владелец передаёт их отдельно.

### Как включить оплату
1. Подключите магазин в ЮKassa, получите `shopId` и секретный ключ (Интеграция → Ключи API).
2. Разверните `server/yookassa/index.js` как облачную функцию (например, Yandex Cloud Functions, Node.js 18+), переменные окружения: `SHOP_ID`, `SECRET_KEY`, `SITE_URL`.
3. Вставьте публичный адрес функции в `index.html`: `<meta name="mentora-payment-api" content="https://...">`.
Пока адрес пустой, кнопка «Оплатить» неактивна. Секретный ключ никогда не кладите в репозиторий.

Режим тестировщика (`?qa=1`) остался только с сервисными кнопками (пройти все уроки, сбросить прогресс), кнопок пробной подписки больше нет.
