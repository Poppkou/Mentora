# Mentora — «Агент в классе»

Практикум по ИИ-агентам для учителей. Одностраничный сайт: весь код в `index.html`.

Открыть локально: скачать `index.html` и открыть в браузере.

Прогресс сохраняется в браузере (localStorage). Функции, которые используют ИИ и облачное сохранение, работают только при запуске сайта внутри Claude.
